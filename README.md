# ZephyrNook

A simple ZephyrNook security-suite for real time data processing.

ZephyrNook is aimed at developers who need a straightforward, dependable solution.

## Technology Stack

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ZephyrNook.git`
2. `cd ZephyrNook`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
